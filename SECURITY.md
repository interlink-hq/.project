# Security Policy

## Reporting Security Issues

The Interlink maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/interlink-hq/interLink/security/advisories/new) form.

For more details, see the [Interlink security policy](https://github.com/interlink-hq/interLink/blob/main/SECURITY.md).
